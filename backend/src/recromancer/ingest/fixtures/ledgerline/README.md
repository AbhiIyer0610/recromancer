# Ledgerline sample bundle

Everything in this directory is fictional. Ledgerline is an invented payments reconciliation service, Priya Raman and her colleagues are invented people, and every commit, pull request, review, issue and document was written for this sample. Any resemblance to a real person, company or system is coincidental.

All links use the reserved host `example.invalid` and lead nowhere.

The bundle is test and demo data for Recromancer. It contains 31 items and a few deliberate gaps: some questions have no answer in the record, on purpose.
